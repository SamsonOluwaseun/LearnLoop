# Contributing

Thank you for helping. LearnLoop is for young children, so please keep changes small, kind and tested.

- Run `node --test tests/*.test.js` before opening a pull request. Add a test for any rule you change.
- Use synthetic names only. Never commit real children's data, screenshots of real use, or passwords.
- New questions follow [docs/CONTENT-AUTHORING.md](docs/CONTENT-AUTHORING.md).
- No analytics, adverts, remote code or network calls in the extension.
- Write in British English and keep wording warm and simple for children.
- Do not claim a feature works on Windows unless it was checked on Windows. Update docs/TEST-REPORT.md.
